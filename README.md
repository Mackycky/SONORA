# SONORA.

**A creative music studio exploring the connection between sound, visual identity and storytelling.**

SONORA. is a creative web project focused on music, visual concepts and artist campaigns. It explores how music can be experienced beyond sound, bringing together visual storytelling, creative direction and digital experiences.

The website presents a curated music selection, artist campaigns, an interactive voting experience and a visual archive, all within a cohesive editorial-inspired design.

---

## About the Project

SONORA. was created as a space to explore the relationship between music and visual communication.

Through its different sections, the project showcases how each artist can have a unique visual identity and how creative campaigns can transform the way music is presented.

## Features

- **Responsive Design:** Adapted for desktop, tablet and mobile devices.
- **Bilingual Interface:** English and Spanish language options.
- **Music Discovery:** A curated selection of songs with Spotify links.
- **New Releases:** A space dedicated to music releases.
- **Artist Campaigns:** Individual campaign pages featuring different artists.
- **Interactive Voting:** Visitors can vote for the artist they would like to see featured next.
- **Visual Gallery:** An editorial-style collection of images.
- **Animated Elements:** Subtle transitions, hover effects and an animated sound wave.
- **Loading Screens:** Custom loading transitions for campaign pages.

## Running the Project

SONORA. is a front-end project and does not require a backend server.

To run it locally:

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the website in your browser.

## Notes

- Campaign voting uses the browser's Local Storage. Votes are stored locally and are not synchronized between different visitors or devices.
- Some external links may be updated as the project evolves.
- The website is designed as a creative portfolio and music discovery experience.
